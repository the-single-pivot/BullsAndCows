Bulls & Cows

Crack the code

Four different digits, 0 to 9. Guess, and every guess comes back scored.

  •   A bull is a digit that is correct and in the right place.
  •   A cow is a digit that is correct but in the wrong place.
  • No digit repeats, and the code can start with 0.
  • Four bulls wins. You get ten guesses, then the code is revealed.

    How to play

    A secret code of four different digits. Guess it. Each guess is scored.

    Bull
    A digit that is correct and in the correct position.
    Cow
    A digit that is correct but in the wrong position.
    3 7 1 4 If the code is 3 4 1 9, that scores 2 bulls and 1 cow. The 3 and the 1 are in place, the 4 is in the code but not in that slot, and the 7 is not in the code at all.
    • The code never repeats a digit, and nor should your guess.
    • It can start with 0.
    • Four bulls wins. You get ten guesses, then the code is revealed.
    • The clock starts on your first digit. Tap it for this session's record.
    • Type on your keyboard, or tap the keypad.

    The board keeps nothing for you

    The keypad stays blank whatever you learn, and no counter tells you how close you are. Every deduction is yours to make from the scored guesses, and yours to remember. Paper is allowed.
